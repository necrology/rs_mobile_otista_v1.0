Ikhtisar dan Struktur

SIPANTES adalah aplikasi Flutter Android (id.rsudotista.sipantes) dengan flutter_bloc, HTTP ApiClient, flutter_secure_storage, path_provider, dan open_filex.

LokasiPeran
lib/coreConfig, network, theme, widget bersama.
lib/features/authOTP, sesi, klaim No. RM, hapus akun.
lib/features/api_dataData pasien dan sumber daya RS.
lib/features/bookingKalender, opsi, booking, riwayat.

Konfigurasi dan Build

Base URL default: https://api-mobile.rsudotista.my.id/api/v1. Override melalui APP_ENV, API_BASE_URL, DEV_API_BASE_URL, atau PROD_API_BASE_URL.

  1. flutter pub get
  2. flutter analyze
  3. flutter test
  4. flutter run
  5. flutter build apk --release --dart-define=APP_ENV=prod

Release memerlukan keystore/key.properties yang aman; jangan commit secret.

Auth dan Keamanan

Registrasi: /auth/register → /auth/verify-otp-new-user → /auth/set-password. Login: /auth/login → /auth/verify-otp. Endpoint personal memakai Bearer token.

  • Token pair disimpan di secure storage.
  • Refresh proaktif dan single-flight pada /auth/refresh.
  • 401 memicu satu refresh dan satu retry; refresh 401 menghapus sesi.
  • allowBackup=false dan usesCleartextTraffic=false pada manifest release.
  • Token/OTP/NIK/No. RM tidak boleh masuk URL atau log.

Endpoint dan Pengujian

Endpoint personal: /mobile/patient/profile, visits, medical-summaries, laboratory-results, radiology-results, prescriptions, booking/general/mine, dan PDF resume. Endpoint publik meliputi poli, jadwal dokter, dan kamar.

  1. Analisis dan test harus lulus.
  2. Uji guest, auth, klaim RM, data personal, booking, refresh, dan PDF memakai akun/data uji berizin.
  3. Verifikasi signing sebelum distribusi.
